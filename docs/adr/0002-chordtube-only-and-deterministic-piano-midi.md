# ADR 0002: コード進行特化・ChordTube限定・決定論的Piano MIDI生成

- 状態: 採用
- 日付: 2026-11-27

## 背景

初期実装（schemaVersion 1.0）ではリズム・メロディー・コードの3要素を対象とし、LLMや手書きで `piano`・`bass`・`drum` のノート番号配列 `MidiClip` を直接記述する方式を採った。しかし実曲で試聴したところ、推測ベースで生成したMIDIは原曲の響きと大きく乖離し、作曲リファレンスとしての実用性を損ねた。

## 決定

1. 分析対象を**コード進行**とユーザーの**フィーリング**に限定し、リズム要素・メロディー要素・ドラム/ベースMIDIをスコープから除外する。
2. 登録対象を `https://chordtube.net/`（ChordTube）で分析済みの楽曲のみに限定し、`source.url` の `https://chordtube.net/` 制約をZodスキーマ（`schemaVersion: "2.0"`）で必須化する。
3. LLMがMIDIノート番号を推測して記述することを禁止し、ChordTubeから読み取ったコード名 `symbol`、度数表記 `roman`、拍数 `beats` のみを保存する。
4. MIDI出力はPianoのみの1トラック構成とし、アプリ内の決定論的音楽理論エンジンがコード記号からボイスリーディング付きで正確なMIDIノート列と `.mid` ファイルを自動生成する。

## 影響

- LLMによる音程誤りやコード進行の捏造を構造的に防げる。
- 登録JSONが軽量になり、ChatGPT経由での継続的な登録・更新の精度と速度が向上する。
- トランスポーズやボイシング変更をブラウザ上でリアルタイムに試聴したうえで、そのまま `.mid` としてFender Studio Proへ持ち込める。
